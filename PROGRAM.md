# Program

Build Yep Anywhere as a mobile-first, multi-session supervisor for local coding
agents across providers, with durable server-owned processes and responsive
browser and native clients that remain useful over direct and end-to-end
encrypted relay connections.

Preserve canonical session identity, provider-native transcript meaning,
reconnect and replay correctness, and explicit control over security, cost, and
provider-specific capabilities. Prefer a self-contained single-user core, lean
dependencies, vanilla provider-compatible defaults, and bounded resource use.
YA supervises, transports, and presents agent sessions; it is not a model
runtime or a hosted multi-user agent service.
